# Product-card-ai-service
AI-помощник для подготовки товарных описаний

## Контракт API

`POST /generate` принимает JSON с полями:

```json
{
  "name": "Манометр показывающий DM 02",
  "manufacturer": "Манотомь",
  "specs": {
    "диапазон измерений": "0–1,6 МПа",
    "класс точности": "1,5"
  },
  "description": "Прибор предназначен для измерения избыточного давления..."
}
```

`specs` и `description` могут быть пустыми; сервис должен сообщить об отсутствующих данных. В ответе предусмотрены SEO-заголовок и описание, характеристики, поисковые запросы, коммерческий блок и список недостающих данных. Значения характеристик переносятся из входа без генерации моделью.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
uvicorn app:app --reload
```

Перед запуском добавьте ключ API в `.env` (`LLM_API_KEY`). По умолчанию используется Mistral. Для совместимого API можно изменить `LLM_BASE_URL` и `LLM_MODEL`.

Swagger UI: <http://127.0.0.1:8000/docs>

## Логи генерации

Логи отображаются в терминале, где запущен Uvicorn. В них видно, завершилась ли генерация с первой попытки или потребовался повторный запрос из-за длины SEO-полей. Текст карточки и API-ключ в логи не записываются.
